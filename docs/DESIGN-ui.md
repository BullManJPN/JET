# JET 画面の設計 (2026-10-30 整理)  流れ型

jetcli のイベント(commit / clause / clause_stale / draft / seg / session)を表示するだけの薄い層。ねらいは「話してから約1.6秒で日本語が読める」こと。

> **整理(10/30)**: 旧版の表示(固定焦点型・ポン差し替え型・歌詞型)、かたまり訳(Gloss)、最終訳(Haiku)、間の強制確定は、コードごと削除した。

## 流れ型 (flow)  10/29 採用
- ねらい: 節ごとの下書き(AFM)は節が閉じた約0.3秒後に出るので、**話してから約1.6秒で読める**(参考: 最終訳は区間が閉じるのを待つので中央値3.8秒・p90 9.6秒かかった。10/29 実測)
- 下書きだけを下に積み上げ、上へ行くほど薄く(`flow_fade` 6行で `flow_min_opacity` 0.2)。新しい行は太字。差し替えも消去もしない(読んでいる行が動かないのが狙い)
- 1かたまり = 日本語(`flow_pt` 19)+ その下にもとの英語(`flow_en_pt` 13、0 で非表示)。英語はその日本語を作るために AFM に渡した節そのもの
- 文字の大きさは行によって変えない(新しい行が来るたびに折り返しが組み直されるのを避ける)
- ガードレールで止まった節は英語の節を日本語の欄に出す(下に英語は重ねない)。clause_stale の節は消さずに ⚠
- 読み返し: 上へスクロールで流れを止め、下に「↓ 最新へ N」。押すか `flow_idle_s`(10秒)触らなければ最新へ
- 設定(jet.json の `ui`): `panel_width`(536)`panel_height`(640)= 最初に開くときの大きさ(以後は窓の位置と大きさを記録して使う)、`flow_pt` `flow_en_pt` `flow_keep`(60)`flow_fade` `flow_min_opacity` `flow_idle_s`
- 使い方: `./menubar.sh`(メニューバー)/ `./jetcli --system --panel`(システム音声)/ `./jetcli --replay-events <イベント>`(音声なし)

### ウィンドウ
- 常に手前の NSPanel(nonactivatingPanel・floating・半透明)、`sharingType = .none`(画面共有に映さない。Web会議の画面共有で確認済み)
- 枠なしの窓を自由に大きさ変更(辺・角のドラッグ。`PanelWindow` の自前 resizeLoop)。移動は上端の帯(28pt)か ⌘+ドラッグ。位置と大きさは `setFrameAutosaveName("JETFlowPanel")` に記録
- `NSHostingView.sizingOptions = []` にして中身が窓の大きさを縛らないようにし、autoresizingMask と frame を明示(中身が 0×0 で窓が透明になりクリックが素通りした問題の対策)。起動時に「パネル: 窓 W×H / 中身 W×H」を出す
- 置き場所の推奨: Webカメラの真下(画面上端の中央)。相手の映像タイルはその下
- 文字サイズは ⌘+ / ⌘−

### 実装上の注意
- 純ロジックは `FlowViewModel`(Flow.swift)、画面は `FlowPanel.swift`、窓と起動の共通部分は `Panel.swift`、設定は `UIConfig.swift`。時計は引数で受け、selftest で試せる
- **メインスレッド**: 再生中はパネルのループがメインスレッドを使い続けるので、`@MainActor` の Task は実行されない。訳や live の処理は Worker(メインの外)で行い、結果は受け箱(`EventInbox`)に入れて 30ms の tick で表示に渡す

## メニューバー (U3)  10/29
- 起動: `./menubar.sh`(`jetcli --menubar`)。起動直後は停止中。Terminal から起動するのでマイク・画面収録の許可は Terminal のもの
- メニュー: 状態(停止中 / 聞き取り中(入力) / 止めています… / エラー)・開始/停止・入力(マイク / システム音声。最後の選択を UserDefaults `JETMenuSource` に記憶)・パネルを隠す/表示・設定ファイルを開く(support の jet.json。Terminal 運用ではリポジトリのルートの `jet.json`)・終了
- メニューバー: 文字「JET」(heavy 13pt、baselineOffset -2 で縦中央)。停止中 `JET` / 聞き取り中 `JET ●` / エラー `JET !`。質問箱のアイコンは `bubble.left.and.text.bubble.right`。帯のうち窓を動かせる範囲だけ、マウスオーバーで薄く色が付く
- 聞き取り1回 = セッション(`Live.run` 1回)。開始ごとに新しいイベントファイル・時計・認識。パネルと表示の中身はセッションをまたいで1つ
- 開始し直してもパネルの行は残す。`session` イベント(Live.run が最初に出す)で流れ型に区切りの行を足し、節の対応表だけ新しくする
- 聞き取り中に入力を切り替え → 止めて(流しきって)から新しい入力で開始。止めている間は開始・入力の操作を無効に
- 設定画面は作らない(設定値がまだ実験で変わるので、jet.json との二重管理を避ける)→ **10/30 U5 で置き換え**: 見た目だけを窓の中の設定パネルで変える(下の「表示の設定 (U5a)」)。認識・翻訳の調整値は jet.json のまま
- 終わりの受け渡し: Task.detached → SessionBox → メニューの 0.2秒タイマー(@MainActor の Task は使わない)

## 質問箱 (10/29 方針)  見た目は音楽プレーヤーの歌詞表示・サイドバーに合わせる
- 質問箱は字幕パネルの左に、同じ半透明の背景・同じ角丸でぴったり付ける(サイドバー風、細い区切り線)。子ウィンドウ・sharingType .none。普段は畳み、最初に語を拾ったら開く
- 読み返し(実装 10/29): 上へスクロールで流れを止め、下に「↓ 最新へ N」のカプセル。押すか `flow_idle_s`(10秒)触らなければ最新へ
- 拾える語はマウスを乗せたときだけ、文字色を濃く(primary)・太い下線(1.5pt)・薄い下地(アクセント 0.14。10/30 に下線だけだと分かりにくいため強めた)。拾った語はカプセル(オン = 塗り / オフ = 枠)。Q ボタンは白いカプセル(再生ボタンのように)。口調は2択のスイッチ
- 出てきた質問: カナ(大・太)/ 英語(中)/ 日本語(小・薄)。クリックで英語をコピー(会議のチャット用)
- 窓の移動(流れ型、10/29): 上端の帯 28pt か ⌘+ドラッグ。角・辺のリサイズは従来どおり。**(10/30 U4) 質問箱の開閉は帯の右端から左のボタンの並びへ移した(下の「窓の操作 (U4)」)**
- 質問箱は子ウィンドウではなく同じ窓の中の左の列で作った(背景・角丸・画面共有に映らない設定を共有でき、位置合わせが要らない)。開くと窓を左へ列の幅ぶん広げる
- 発言を作る(10/29): 入力欄(言いたいこと)+ Q。型への差し込みはすぐ、AFM の案は1〜2秒後に先頭へ。失敗は「何が起きたか + 次にどうすればよいか」をオレンジで出す

## 窓の操作 (U4)  10/30 実装・実機確認済み  チャットアプリの左サイドバーのような動き
```
 ┌ × ▶︎/❚❚ ?⃝ ─────────────── (帯 28pt: ここをつかむと窓が動く) ┐
 │ [質問箱: 重ね表示]│ 字幕(流れ型)                             │
 │                    │                                         │
 └──────────────────────────────────────────┘
```
- **帯の左のボタン**: × / 開始・ポーズ / 質問箱のアイコン(左から)。× と 開始・ポーズは**帯にマウスを乗せたときだけ**出す。質問箱のアイコンはいつも出す(帯の外では薄く)。ボタンの並びの幅は窓を動かさず、角のリサイズより優先(外側 6pt の辺だけはリサイズ)
  - 位置と幅は `BarLayout`(PanelBar.swift)。窓の当たり判定と SwiftUI の見た目で同じ値を使う。帯は文字サイズ(⌘+ / ⌘−)で変えない
  - マウスの位置は窓の NSTrackingArea(`.activeAlways`)で受ける(`PanelWindow.trackPointer` / `onPointer`)。アプリが前面になくても帯・アイコン・窓から出たことが分かる
- **×**: 完全終了。メニューの「終了」・⌘Q・Ctrl-C と同じ経路(聞き取りを止め、イベントを書き終えてから終了。止まらなければ5秒で終了)
  - 聞き取り中は2段階: 1回目でその場で赤いカプセル「終了する?」に変わり、4秒以内(`QuitGate.armTimeout`)のもう一度で終了。4秒たつか帯からマウスが離れると元に戻る。ポーズ中・停止中は1回で終了。終了を始めたら「終了中…」
- **開始・ポーズ**: メニューバー(`./menubar.sh`)のときだけ出す。ポーズ = メニューの「ポーズ」(旧「停止」)と同じ(流しきって止まり、字幕の行は残る。再開すると区切りの行)。止めている間は砂時計の代わりに小さな回転
  - live(`./jetcli --system --panel`)は開始・ポーズなし。× と ⌘Q は入力を止めてイベントを書き終えてから終了。1回目の Ctrl-C は従来どおり入力だけ止める(パネルは残る)
  - 再生(`--replay-events`)は × で すぐ終了
- **質問箱の3段階**(`QBoxPresence`、selftest bar):
  1. 隠す(普段): 左上にアイコンだけ
  2. 重ね表示: アイコンにマウスを乗せる → 字幕の上、帯の下に左から重ねて出す(窓の大きさは変えない。字幕より濃い背景と影。中の操作もできる)。幅は列の幅(`JETQBoxWidth`)で、窓の幅 − 48pt まで。境目のドラッグは固定のときだけ
  3. 固定: アイコンをクリック(隠す・重ね表示のどちらからでも)→ いまと同じ左の列(窓が左へ広がり、字幕は動かない)。固定中にクリック → 隠す
  - 重ね表示を閉じるのは**窓全体からマウスが出たとき**。入力欄にカーソルがある(窓がキーのときだけ数える)/ AFM が生成中なら閉じずに待つ。待っている間に入力欄から抜けた・ほかのアプリをクリックした(窓の外にいれば)→ 閉じる。AFM の案ができたら待ちは取り消し(結果を読めるよう開いたまま。次に窓から出たら閉じる)
  - 質問箱から字幕の側へ移っただけでは閉じない(語を拾うのは字幕の側)
  - 最初に語を拾ったときに自動で開くのは固定(いまと同じ)。重ね表示中に拾ったときは重ね表示のまま
- 実装: 新規 `jet/PanelBar.swift`(BarLayout・QuitGate・QBoxPresence・PanelControls・PointerTracker・PanelBarView・BarSelftest)。変更: Panel(帯の左の当たり判定・trackPointer・DisplayParts.controls)/ FlowPanel(3段階・重ね表示・帯)/ QBoxPanel(入力欄のカーソルを渡す)/ Menubar(帯のボタン・「ポーズ」・Ctrl-C も「終了」へ)/ LivePanel(停止フラグを持ち × と ⌘Q で止めてから終了)/ Jet(selftest bar)

## 表示の設定 (U5a)  10/30 実装・実機確認済み
```
 ┌ × ▶︎/❚❚ ?⃝ ──────────────────────────────── ⚙ ┐
 │ 字幕(流れ型)                  │ 表示の設定            × │
 │                                │ 背景の濃さ  ○──●── 60%  │
 │                                │ 外観  [自動|明るい|暗い]│
 │                                │ 字幕のフォント ✓システム│
 │                                │ 文字の大きさ 日本語 19pt│
 └──────────────────────────────────────────────┘
```
- **歯車**: 帯の右端(`BarLayout.rightTrail` 8pt + `slot` 26pt)。帯にマウスを乗せたとき・設定を開いているときだけ出す。窓はこの幅(`BarLayout.rightWidth`)を動かさず、角のリサイズより優先(外側 6pt の辺だけはリサイズ)。`PanelWindow.barButtonWidth` と `FlowPanelModel.pointer`(窓の右端からの距離)で判定
- **設定パネル**(`SettingsPanel.swift`): 字幕の上・帯の下に右から重ねる(幅 240〜300pt、窓の高さいっぱい、質問箱の重ね表示と同じ濃い背景と影)。**別ウィンドウ(NSPopover・NSColorPanel・メニュー型の Picker)を使わない**(sharingType .none を共有するため)。外観は segmented、フォントは見本付きの行で選ぶ。中の文字は ⌘+ / ⌘− で変えない
- **背景の濃さ**(`LookValues`、Appearance.swift): 0.1〜1.0。0.6 = すりガラス(`ultraThinMaterial`)だけ = いままで。0.6 未満はすりガラスの不透明度を d/0.6 に、0.6 超は窓の背景色の膜を (d−0.6)/0.4 × 0.85 重ねる。下限 0.1 は「窓が見えなくなってつかめない・クリックが素通りする」のを防ぐため
- **縁取り**(`SubtitleHalo`): 0.6 未満で強さ (0.6−d)/0.5。窓の背景色の影を2重に(明るい外観なら白、暗い外観なら黒の縁)。1かたまりを `compositingGroup` でまとめてから影を付ける(語ごとだと重い)
- **固定した質問箱の列**: 背景を薄くしたぶん(1 − すりガラスの不透明度)だけすりガラスを足して、いままでの読みやすさを保つ。重ね表示の質問箱はもともと濃い背景なので変えない
- **外観**: `NSWindow.appearance`(nil / aqua / darkAqua)で窓ごと切り替える。すりガラス・`Color.primary` / `.secondary`・ボタンがそろって変わる
- **フォント**(`SubtitleFont`): 字幕の本文(日本語と英語の語)だけ。ヒラギノは regular → W3、semibold → W6(丸ゴは W4 だけ)
- **保存**(`LookStore`): 変えたら 0.5秒後(終了時にも)。`jet.json` の `ui` に既定(同梱の jet.json)と違う項目だけを書く。保存先は `JetPaths.userConfig`(.app = support の jet.json、Terminal = `<リポジトリのルート>/jet.user.json`)
- **質問箱の型(U5b、10/30 実装・実機確認済み)**: 設定パネルの最後の欄。「質問箱の型(N 件)」+「ファイルを開く」「再読み込み」+ 警告 + 型ファイルの場所 + 「一覧を見る」(分類ごと。日本語の見出し・ビジネス・フランクの英語)。ファイルは `TemplateFile`(読む = support の編集版 → 同梱 / 開く = 初回に同梱を support へコピーして TextEdit)。読み込みは `QTemplate.report`(列が8つに足りない行は行番号、id の重複は最初の行だけ、`slot=1` で `___` が無い型を知らせる)→ `QBox.replaceTemplates`(オンの型はまだあるものだけ残す)。自動で読み直すのは、設定を開いたとき・設定を開いている間に窓がキーになったとき(ファイルの更新日時が変わっていれば)
